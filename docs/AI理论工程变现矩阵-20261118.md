# AI 理论—工程—变现矩阵（2026-11-18）

> 回应"范式智能的理论与我们关于 AI 的理论讨论存多大关联"：
> 把"基础理论 / 工程平台 / 行业应用 / 变现"分开，避免把"工程突破"当"理论突破"。

## 一、四层框架

| 层 | 内容 | 关键问题 | 代表 |
|---|---|---|---|
| **T0 基础理论** | 学习理论、Scaling Law、智能本质、世界模型 | 智能从哪来？能否泛化？ | 极少公司涉及；范式是 ML 方法论，不是 T0 |
| **T1 算力/硬件** | 芯片、服务器、PCB、电源、IDC | 算力够不够、成本 | 弘信、协创、科翔、特锐德、数据港、光环 |
| **T2 平台/工具链** | AutoML、MaaS、模型平台、云 | 能不能低门槛生产模型 | 范式、中贝（MaaS）、东华（腾讯云）、云从 |
| **T3 行业应用** | 工业、金融、医疗、零售、Agent | 能不能解决业务问题 | 赛意、东华、云从、范式 |
| **T4 变现** | API/Token、订阅、项目制、服务费 | 能不能收钱/复购 | 范式（API+860.8%）、中贝、杰创、平治 |

## 三、关键判断

1. **"理论突破"极少**：多数公司是工程化/应用/变现，不是基础理论；
2. **范式智能**：理论含量中等（迁移学习/AutoML 是成熟 ML），工程化强，变现证据最好（API/Token）；
3. **"第四范式"名字**来自数据密集型科学概念，不是公司理论；
4. **投资/研究价值不在"理论"**，而在"工程化能力 + 变现闭环"；
5. 真正接近 T3/T4 的：范式、东华、赛意、云从；T1/T2 的：中贝、弘信、协创、数据港。

## 四、对我们 AI 理论讨论的补充

- 我们讨论"AI 是否形成生产力"，对应 **T3/T4**；
- 范式智能是 **T2→T3→T4** 的样本，不是 T0 理论样本；
- 评估公司时，应问：
  - 它有没有**工程化能力**（平台/工具/交付）？
  - 有没有**变现证据**（API/Token/订阅/复购）？
  - 有没有**现金流**（OCF/应收）？
- 不要用"理论突破"给估值，除非有独立论文/引用/第三方验证。

## 五、结论

> **范式智能与"AI 基础理论"关联低，与"AI 工程化/变现"关联高；它更适合放在 T2/T3/T4，而不是 T0。**
> 我们的研究重点应继续放在"工程化+变现+现金流"，而不是"理论故事"。
