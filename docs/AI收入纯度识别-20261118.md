# AI 收入纯度识别（2026-11-18）

> 研究问题：识别"AI 名义与实质不匹配"的信号。
> 研究上不能直接定罪，但可以用一组指标识别"AI 名义 vs 贸易/硬件实质"。

## 一、识别指标（六问）

| 指标 | 危险信号 |
|---|---|
| **1. AI 收入纯度** | "AI 收入"里贸易/硬件占比高；扣除后营收大幅缩水 |
| **2. 毛利率异常** | 硬件贸易毛利率 100%、成本 0（净额法） |
| **3. 客户/供应商** | 客户一/供应商一占比 50%+，匿名、新进入 |
| **4. 现金流** | 高毛利但 OCF 大幅负、存货/应收暴增 |
| **5. 可持续性** | 下一年贸易消失、收入断崖 |
| **6. 研发/团队** | 研发人员减半、核心团队流失 |

## 二、安博通：结构上高度符合

| 指标 | 数据 |
|---|---|
| AI 收入纯度 | 2025"安全 AI"3.75 亿，其中贸易 3.31 亿（AI 硬件组件 3.29 亿） |
| 扣除后营收 | 5.56 亿 → **2.24 亿（-61.55%）** |
| 毛利率 | AI 硬件贸易 **100%（成本 0，净额法）** |
| 客户/供应商 | 客户一 58.94%、供应商一 46.75% 且新进 |
| 现金流 | OCF -2.23 亿；存货 +363% |
| 可持续性 | 2026H1 贸易消失、营收 -69.46% |
| 研发 | 185 → 94 人（-49%） |
| 监管 | 2025 年报被问询 |

**判断：结构上符合"AI 名义 + 贸易实质"画像；公司/审计称有真实商业实质，最终需监管/审计结论。**

## 三、23 家里的"AI 纯度"粗分

| 类型 | 公司 | 说明 |
|---|---|---|
| **真算力/服务收入** | 杰创、平治、中贝、弘信、协创 | 有算力收入/服务器/服务，但仍需看毛利/现金流 |
| **AI 名义+贸易/硬件** | **安博通** | AI 硬件贸易占 59%、毛利 100% |
| **配套/卖铲子** | 特锐德、科翔、数据港、光环 | 不是 AI 运营，但业务真实 |
| **跨界/未放量** | 亿田、康惠、华孚、东方新能、安诺其 | 算力占比小/未验证 |
| **IDC/云** | 数据港、光环 | 真实但 AI 应用弱 |

## 四、为什么"AI 名义与实质不匹配"危害大

1. **误导资源配置**：把贸易/渠道包装成 AI，骗取估值/补贴/政策；
2. **掩盖真实竞争力**：研发/产品没起来，用贸易做收入；
3. **伤害行业信誉**：真做 AI 的公司被"劣币"拖累；
4. **投资者风险**：收入不可持续，现金流/存货风险暴露。

## 五、研究纪律

- 不写"造假"，写"**收入质量/商业实质待核**"；
- 区分"贸易本身合法"与"以 AI 名义误导披露"；
- 看**扣除后营收、毛利率、客户/供应商、OCF、下一年可持续性**；
- 监管问询/审计意见是重要证据，但不等于最终结论。

## 六、结论

> **安博通是"AI 纯度最低"的样本：AI 安全收入里贸易占 59%、毛利 100%、客户/供应商高度集中、2026H1 贸易消失。**
> 结构上符合"AI 名义与实质不匹配"的画像，但法律结论要等监管；研究上先标"高危/待核"，不跟风、不洗白。
