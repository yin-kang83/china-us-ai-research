# 亿田智能（300911）深度核验（2026-11-18）

> 来源：2024–2025 年报、2026H1/Q3 财报；研究性分析，不构成投资建议。

## 一、结论（先看）

| 项 | 判断 |
|---|---|
| **AI 纯度（研究）** | **2/10**（H1 算力 0.23 亿，占比约 38% 但体量极小） |
| **风险分（研究）** | **8/10** |
| **主业** | 集成灶/厨电，收入大幅下滑 |
| **财务** | 2026Q3 营收 1.53 亿、净利 -0.79 亿、OCF +0.05 亿；现金 1.36 亿 |
| **关键风险** | 主业萎缩、持续亏损、现金薄、跨界算力未放量 |

> 典型"主业下滑 + 跨界算力"：算力收入占比看似高，但绝对额只有 0.23 亿；不能当"AI 转型成功"。

- 现金从 9.26 亿降至 1.36 亿。

## 三、算力业务

| 项 | 内容 |
|---|---|
| H1 算力收入 | 0.23 亿 |
| 占比 | 约 38%（分母小，绝对额小） |
| 模式 | 算力服务/设备 |
| 风险 | 预付/营收高（约 77.8%）、客户/执行 |

> 算力占比"高"是因为主业缩得厉害，不是算力做大；绝对额仍小。

## 四、风险点

1. **主业萎缩**：厨电需求/竞争，营收连续下滑；
2. **持续亏损**：2025/2026Q3 均亏；
3. **现金薄**：1.36 亿；
4. **算力体量小**：0.23 亿，难对冲主业；
5. **预付/营收高**：约 77.8%，资金占用/供应商风险；
6. **跨界执行**：团队/客户/技术待验证。

## 五、什么能确认/证伪

**确认：**
- 算力收入放量（>1 亿/年）；
- 主业止跌/扭亏；
- 现金/OCF 改善；
- 算力合同/客户落地。

**证伪：**
- 算力收入停留在千万级；
- 主业继续下滑、亏损扩大；
- 现金继续消耗。

## 六、判断

> **亿田是"主业下滑 + 小体量算力"样本：算力占比高是分母效应，绝对额只有 0.23 亿；不能当 AI 转型成功。**
> 跟踪：算力收入放量、主业止跌、现金。
