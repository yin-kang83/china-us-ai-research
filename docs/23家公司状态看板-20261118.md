## 二、分组结论

| 组 | 公司 | 特征 |
|---|---|---|
| **真算力收入 + 高风险** | 赛意、康惠、杰创、平治、协创 | 收入出现，但 OCF/杠杆/诉讼 |
| **真算力收入 + 中等风险** | 弘信、行云、中贝、安诺其、光环 | 收入真，现金流/治理待改善 |
| **重资产/建设期** | 科翔、亿田、华孚、东方新能 | 投入大、收入未验证 |
| **稳健/低风险** | 宝信、数据港、特锐德、东华、广电 | 财务稳，AI 弹性小 |
| **小体量/亏损** | 云从 | 需减亏/新合同 |
| **监管问询/收入质量待核** | 安博通 | 贸易业务占 59%、供应商集中且新进、安全 AI 毛利 90.91% |
