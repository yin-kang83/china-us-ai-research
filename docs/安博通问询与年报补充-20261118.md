# 安博通问询函 + 年报员工/研发补充（2026-11-18）

> 来源：巨潮 2025 年报、2025 年报问询函回复（2026-07-07）。
> 问询≠违规结论；但属于重要风险信号。

## 一、安博通：2025 年报被监管问询

| 项 | 数据/问题 |
|---|---|
| 2025 营收 | **5.56 亿元** |
| 其中贸易业务收入 | **3.31 亿元（59.35%）**，同比 **+114.56%**，主要为安全人工智能（模组产品销售） |
| 安全人工智能收入 | **3.75 亿元**，同比 **-15.71%**，毛利率 **90.91%** |
| 前五名供应商采购 | **2.29 亿元（75.33%）**，供应商一/二/四/五均为**新进入** |
| 监管问询重点 | ① 贸易业务/安全 AI 收入构成，是否应营收扣除；② 贸易业务商业实质、关联关系、合同/交付/收入确认；③ 前五大供应商变动原因 |
| 公司回复要点 | 安全 AI 是 2024 年新业务，含 AI 安全软件平台、AI 安全硬件组件、安全算力基础设施；供应商变化因业务拓展/硬件采购 |

**风险判断：**
- 贸易业务占营收 59%、同比翻倍、供应商高度集中且多为新进入——**收入质量/商业实质待核**；
- 安全 AI 毛利率 90.91% 异常高，需核对成本口径；
- 监管已问询，说明交易所关注；
- **风险评分由 4 → 7（中高）**：不是"造假"结论，是"收入质量/关联/商业实质待核"。

## 三、影响

1. **安博通**：小体量（241 人）+ 贸易业务占比高 + 研发减半 + 监管问询 → 风险显著上升；
2. **杰创**：517 人、研发 149（28.8%），支撑算力运营+49 亿合同，但研发在缩；
3. **安诺其**：721 人、研发 133（18.5%），染料+算力跨界，研发一般；
4. **广电运通**：33,765 人、研发 3,114（9.2%），体量大、研发绝对值高，但占比低。
