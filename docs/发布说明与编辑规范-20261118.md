# 发布说明与编辑规范（2026-11-18）

> 本目录为**公开研究材料**，只保留可核查的证据、数据来源与研究结论。

## 一、公开版边界

1. **不收录非公开对话内容、未公开材料、情绪化评价**；
2. **不写未经监管/审计确认的"造假/欺诈"结论**；统一用"收入质量/商业实质待核"；
3. **不包含密钥、账号、个人隐私、客户实名**（对手方用 A/B/C 或"匿名客户"）；
4. **不构成投资建议**；数据可能滞后/有误，以公司公告和原始财报为准；
5. 引用第三方数据时标注来源与日期。

## 二、证据等级

| 等级 | 含义 |
|---|---|
| verified | 公司公告/财报/审计报告/官方数据 |
| observed | 公开报道/行业数据/可复核信息 |
| inferred | 基于数据的推断（需标注"推断"） |
| unknown | 暂无法核实（不写结论） |

## 三、写作规范

- 结论必须能回溯到"数据/来源/日期"；
- 不用"必然/一定/造假"等绝对化措辞；
- 对"异常"只描述结构（如"贸易占比 59%、毛利 100%、客户集中 59%"），不替监管下结论；
- 图表/表格优先，避免空话；
- 匿名处理：客户、供应商、对手方统一代号。

3. 若未来要把仓库公开，必须先重写/压缩历史（破坏性操作，需明确同意），或新建干净仓库；
