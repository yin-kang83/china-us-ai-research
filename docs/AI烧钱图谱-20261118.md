# AI 烧钱图谱（2026-11-18）

> 结论：AI 算力是**重资产、长周期、先烧钱后回收**的生意；"烧钱"本身不是问题，
> 问题是**烧完能不能变成收入、回款、现金流**。
> 数据来自 2026Q3 财报/公告；未审计口径，仅作研究。

## 四、结论

1. **AI 是真烧钱**：设备、机房、电力、融资租赁，四头烧；
2. **但烧钱分两种**：
   - 有订单/收入/回款支撑 → 投资；
   - 只有合同/框架/股价，没有收入/回款 → 风险；
3. **当前证据**：
   - 真烧出收入的：中贝、平治、杰创、安诺其（小）；
   - 烧钱但收入未验证：科翔、赛意、亿田、康惠；
   - 现金厚但算力小：东阳光、数据港、广电、华孚、特锐德；
4. **下一阶段核心指标**：capex/营收、预付/营收、应收/营收、OCF/净利、合同负债/营收；
5. 不因"烧钱"否定 AI，也不因"合同大"忽视现金流。
