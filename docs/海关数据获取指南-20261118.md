# 海关数据获取指南（2026-11-18）

> 用途：查中国集成电路/半导体设备/算力硬件的进出口，做 L1 算力/芯片对照。
> 原则：优先官方一手；UN Comtrade 做交叉；付费库做补充。

## 一、官方渠道（免费）

| 渠道 | 地址 | 能查什么 |
|---|---|---|
| **海关总署官网** | `http://www.customs.gov.cn/` | 统计数据、统计月报、统计快讯、政策 |
| **海关统计数据在线查询平台** | `http://stats.customs.gov.cn/` | 按 HS 编码/商品/贸易伙伴/时间查进出口值、数量；可导出 |
| **海关统计月报/快讯** | 海关总署官网 → 政务公开 → 统计数据 | 月度汇总、主要商品 |
| **国家统计局** | `https://www.stats.gov.cn/` | 宏观/工业/高技术产业补充 |
| **商务部** | `http://www.mofcom.gov.cn/` | 贸易政策/进出口形势 |
| **工信部** | `https://www.miit.gov.cn/` | 电子信息/半导体行业运行 |
| **中国半导体行业协会** | `http://www.csia.net.cn/` | 行业数据/报告（部分会员） |

> 注：海关官网有反爬（直接抓可能 412），用浏览器正常访问；在线查询平台通常需注册/登录后查询导出。

## 二、国际交叉（免费）

| 渠道 | 地址 | 用途 |
|---|---|---|
| **UN Comtrade** | `https://comtradeplus.un.org/` | 各国进出口，HS6 口径；可 API |
| **UN Comtrade 预览 API** | `https://comtradeapi.un.org/` | 脚本拉取（我们已用） |
| **WTO Stats** | `https://stats.wto.org/` | 贸易总量/关税 |
| **ITC Trade Map** | `https://www.trademap.org/` | 贸易流向（部分免费） |

## 三、相关 HS 编码

| HS | 内容 | 用途 |
|---|---|---|
| **8542** | 集成电路 | IC 进口/出口 |
| **8486** | 半导体设备/零件 | 设备进口 |
| **8541** | 半导体器件/LED/传感器 | 分立器件 |
| **8471** | 计算机/服务器 | 算力硬件 |
| **8473** | 计算机零件 | 服务器零部件 |

> 中国海关用 8/10 位编码，UN Comtrade 用 HS6；做国际对比用 HS6，国内细分用海关编码。

## 四、查询步骤（在线平台）

1. 打开 `http://stats.customs.gov.cn/`；
2. 注册/登录（按平台要求）；
3. 选"数据查询"→ 商品/HS 编码（如 8542）→ 进出口 → 贸易伙伴（世界/美国/台湾等）→ 时间（月度/年度）；
4. 选"价值/数量"口径；
5. 导出 Excel/CSV；
6. 记录：查询日期、HS 版本、口径、数据修订状态。

## 五、口径与坑

1. **价值 vs 数量**：金额受价格/汇率影响，数量看真实规模；
2. **加工贸易/保税区**：可能重复统计或虚增；
3. **HS 版本变化**：不同年份编码可能调整；
4. **转口/香港**：贸易流向可能经第三地；
5. **初步数据会修订**：用最新版本，标注"初步"；
6. **AI 芯片没有单独 HS**：只能用 8542/8471/8486 近似，不能直接说"AI 芯片进口"。
