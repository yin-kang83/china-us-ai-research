# 行云科技（300209）深度核验（2026-11-18）

> 来源：2024–2025 年报、2026H1/Q3 财报、公告；研究性分析，不构成投资建议。
> 行云科技为更名后主体（原天泽信息）；数据以公告为准。

## 一、结论（先看）

| 项 | 判断 |
|---|---|
| **AI 纯度（研究）** | **5/10**（算力租赁/销售，收入真但毛利/粘性待验证） |
| **风险分（研究）** | **8/10**（治理/杠杆/客户集中） |
| **执行证据** | **最强**：租赁起租 + 销售验收 + 营收放量 |
| **财务** | 2026Q3 营收 11.75 亿、净利 2.70 亿、OCF +2.38 亿；总负债 44.21 亿、净资产 12.38 亿 |
| **关键风险** | 规模突增、杠杆高、客户集中、治理处罚/内控非标 |

> 它是"执行证据最强"的样本，但"真收入"不等于"低风险"；治理/杠杆/客户集中要盯。

## 四、风险点

1. **规模突增**：2025 营收 1.45 亿 → 2026Q3 11.75 亿，需看可持续性；
2. **杠杆高**：总负债 44.21 亿、净资产 12.38 亿；
3. **客户集中**：算力合同/客户集中，续约风险；
4. **治理**：处罚/内控非标，需整改；
5. **团队小**：108 人支撑 11.75 亿营收，人均高，需看外包/贸易成分；
6. **毛利/粘性**：租赁/销售毛利率、续约率待验证。

## 五、什么能确认/证伪

**确认：**
- 2026 年报算力收入/毛利/客户集中度；
- 47.36 亿合同执行/回款；
- 负债结构/利息成本；
- 治理整改完成。

**证伪：**
- 收入靠一次性销售/贸易，不可持续；
- 客户不续约、应收/存货上升；
- 杠杆继续上升、OCF 转负。

## 六、判断

> **行云是"执行证据最强、治理风险最高"的样本：起租/验收/收入都真；但规模突增、杠杆高、团队小、治理有瑕疵。**
> 跟踪：合同执行/续约、毛利、负债、整改。
