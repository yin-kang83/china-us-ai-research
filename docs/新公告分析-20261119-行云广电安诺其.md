# 新公告分析：行云/广电/安诺其（2026-11-19）

> 来源：巨潮公告原文 PDF（2026-11-18/19）；研究性分析，不构成投资建议。
> 重点：行云 AI 词元跨境销售合同、广电农行超级柜台中标、安诺其智算子公司注册。

## 一、行云科技（300209）

### 公告要点

| 项 | 内容 |
|---|---|
| 公告 | 关于公司签订日常经营重大销售合同的公告（2026-153） |
| 对手方 | 新丝路控股集团有限公司（港股上市，注册地百慕大） |
| 合同 | 《AI 词元跨境销售服务合同》《销售订单》 |
| 金额 | 累计结算金额 **上限 20 亿元（含税）**；首期采购 **2 亿元（含税）** |
| 期限 | 60 个月 |
| 服务 | AI 词元服务，API 调用，按实际调用量计价 |
| 场景 | 食品研发、AI 育种、数字内容生成、全球贸易等；服务区域含韩国 |
| 交付 | 首批节点 **2027-06-30 前**具备服务能力 |
| 关联 | 不构成关联交易 |

### 判断

1. **首期 2 亿是实质订单**，但 20 亿是"累计结算上限"，后续采购以订单为准，**不构成对手方采购承诺**；
2. 对手方为港股上市、业务含房地产/物业/跨境电商/影视传媒/K-POP 投资，**不是纯 AI 客户**；
3. 从"算力租赁/销售"延伸到"AI 词元/API 服务"，若执行，毛利率/粘性可能优于硬件；
4. 风险：跨境/韩国合规、对手方履约、按调用量结算、2027 年才交付；
5. 不能把 20 亿当收入；**首期 2 亿、实际调用量**才是验证点。

### 对行云评分的影响

- AI 纯度：暂维持 5（模式升级，但收入未兑现）；
- 风险：维持 8（对手方/跨境/执行）；
- 观察：首期 2 亿订单执行、2027-06-30 交付、调用量/回款。

## 二、广电运通（002152）

### 公告要点

| 项 | 内容 |
|---|---|
| 公告 | 关于收到中标通知书的公告（临 2026-048） |
| 项目 | 中国农业银行超级柜台入围项目（非现金超柜/打印边柜、现金超柜） |
| 金额 | 预计合计约 **3 亿元（含税）** |
| 期限 | 采购有效期 3 年 |
| 状态 | 收到中标通知书，**尚未签订正式合同**；农行不承诺采购规模 |

### 判断

- 这是**智能金融设备**中标，不是算力/AI 智算合同；
- 3 亿/3 年，对广电营收有积极影响，但不改变"AI 纯度低"的判断；
- 风险：未签正式合同、采购量不确定。

## 三、安诺其（300067）

### 公告要点

| 项 | 内容 |
|---|---|
| 公告 | 关于设立全资子公司的进展公告（2026-090） |
| 子公司 | 烟台安诺其智算科技有限公司 |
| 注册资本 | 3 亿元 |
| 项目 | 智算中心，投资 **5.8 亿元** |
| 状态 | 2026-11-16 完成工商注册 |

### 判断

- 智算中心从"公告"进入"子公司落地"，执行推进；
- 5.8 亿投资 vs 公司现金/负债需看资金来源；
- 尚未产生算力收入，AI 纯度/风险暂不变（2/6），跟踪投产/客户。

## 四、结论

> **行云：AI 词元合同 20 亿是"上限"、首期 2 亿是实质订单；模式升级但未兑现。**
> **广电：3 亿农行中标是传统智能设备，不是算力。**
> **安诺其：智算子公司落地，投资 5.8 亿，尚未收入。**
