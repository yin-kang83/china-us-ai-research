# 中国大厂开发者平台评分（2026-11-18）

> 研究性评分，不是投资建议；基于公开信息，缺平台收入/开发者数/分成比例，分数为方向性判断。
> 评分维度：算力/模型、开发工具、分发/流量、变现/分成、开放/迁移，各 0–2 分，总分 10。

## 二、分项判断

### 1. 字节：流量最强，变现待建

- 扣子 Coze 低代码 Agent + 豆包流量入口；
- 优势：分发/用户规模；
- 短板：分成/支付/企业采购闭环未成熟。

### 2. 阿里：模型/云最强，分发弱

- 百炼 + 魔搭社区 + 阿里云算力；
- 优势：模型供给、开源、云客户；
- 短板：缺超级 App 级开发者分发入口。

### 3. 百度/腾讯/华为：各有入口

- 百度：千帆 + 文心 + 搜索/地图入口；
- 腾讯：微信/企微/QQ 入口 + 腾讯云；
- 华为：昇腾/行业云 + 政企渠道；
- 共同短板：分成/支付/独立开发者变现规则不透明。

### 4. 模型公司：有 API，缺平台

- 智谱/DeepSeek/月之暗面：模型 API 强，但缺分发/计费/应用市场；
- 独立开发者用它们做产品，变现要靠自己。

## 三、谁最接近"全链路"

| 平台 | 最接近的链路 | 缺什么 |
|---|---|---|
| **字节** | 工具→流量→用户 | 分成/支付/企业采购 |
| **阿里** | 算力→模型→云客户 | 超级 App 分发 |
| **腾讯** | 流量→支付→企业 | 开发者工具/模型 |
| **华为** | 算力→行业客户 | 独立开发者生态 |

> 没有一家同时做到"算力+工具+分发+变现+开放"；**字节最接近消费端，阿里最接近企业端。**

## 四、评分缺口

- 平台收入/开发者数/API 调用量：未公开；
- 分成比例/结算周期：不透明；
- 开发者留存/迁移成本：缺数据；
- 政策/合规成本：难量化。

## 五、结论

> **中国大厂在"算力/模型/工具"上不弱，弱在"分发+变现+开放"的闭环；字节和阿里最接近全链路，但都没跑通"开发者赚钱"这一环。**
> 谁先做出透明分成、可迁移、能赚钱的开发者平台，谁就能在 L4/L5 建立生态护城河。

## 六、重要说明：平台分 ≠ 模型分

> 这个评分只衡量“开发者平台全链路”（算力/工具/分发/变现/开放），**不衡量模型能力、研究水平或开源贡献**。

| 维度 | DeepSeek 的位置 |
|---|---|
| **模型能力** | 第一梯队：AAII 53（第6）、开源权重代表 |
| **平台生态** | 低分：API 为主，缺应用市场/分发/分成 |

- DeepSeek 平台分低，不是模型弱，而是它**没做“开发者平台”这件事**；
- 如果评“模型能力/开源影响力”，DeepSeek/Kimi/Qwen 会排前面；
- 平台分低也可能是一种战略选择：专注模型与研究，把应用层留给别人。

> 一句话：**平台评分看“生态”，模型评分看“能力”；两张榜不能混。**
