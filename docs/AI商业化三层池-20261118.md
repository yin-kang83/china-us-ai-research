# AI 商业化三层池（2026-11-18）

> 回应"大厂也未必商业化好"：把 AI 分成三层池，分别用不同指标看，避免混为一谈。
> 仅研究框架，不构成投资建议。

## 一、三层池

| 层 | 主体 | 核心问题 | 关键指标 |
|---|---|---|---|
| **L0 前沿实验室** | DeepSeek、智谱、月之暗面、上海 AI Lab、大厂研究院 | 模型能力/理论突破 | 论文/榜单/开源/人才/融资 |
| **L1 大厂 AI** | 阿里、腾讯、百度、字节、华为、Google、Microsoft、Meta、Amazon | 能否把 AI 嵌入现有业务并变现 | 云收入/广告增量/capex/推理成本 |
| **L2 上市公司（我们的样本）** | 23 家算力/平台/应用公司 | 合同→收入→现金流 | 算力收入/毛利率/OCF/应收 |

## 二、L0 前沿实验室：看"能力"

- **DeepSeek**：开源/低成本训练，模型能力接近头部；
- **智谱**：GLM 系列，企业/政企；
- **月之暗面**：长上下文/Kimi；
- **上海 AI Lab**：开源/具身智能；
- **大厂研究院**：阿里 Qwen、百度文心、字节 Seed、华为诺亚；
- 变现：API/企业合同/云捆绑，多数未独立盈利；
- **判断：能力≠商业化，L0 需要长期资本。**

## 三、L1 大厂：看"嵌入与分摊"

| 公司 | AI 变现方式 | 观察点 |
|---|---|---|
| **阿里** | 云+Qwen+电商 | 云收入增速/利润率、AI 资本开支 |
| **腾讯** | 广告/游戏/云+混元 | AI 对广告效率、云收入贡献 |
| **百度** | 搜索广告+云+文心 | 搜索被分流程度、云增速 |
| **字节** | 豆包+广告/电商 | 未上市，看投入/生态 |
| **华为** | 昇腾/云/盘古 | 算力生态、政企订单 |
| **Google** | 搜索/广告/云/Gemini | AI 搜索对广告影响、云增速 |
| **Microsoft** | Azure/OpenAI/Copilot | Copilot 付费渗透、Azure AI |
| **Meta** | 广告推荐/开源 | AI 对广告 ROI、capex |
| **Amazon** | AWS/Bedrock | 云增速、推理价格 |

**大厂难点**：AI 收入难拆分、capex 先走、推理成本高、模型商品化、用 AI 防守而非创收。

## 四、L2 我们的样本：看"合同→现金流"

| 指标 | 含义 |
|---|---|
| 算力收入/占比 | 是否真形成收入 |
| 算力毛利率 | 贸易/租赁 vs 服务 |
| OCF/净利 | 利润是否变现金 |
| 应收/营收 | 回款质量 |
| 预付/营收 | 向上游垫资 |
| 合同负债/预收 | 客户是否先付钱 |

## 五、三层池的关系

1. **L0 提供能力**，L1 提供分发/资本，L2 提供工程/交付；
2. **L0 不一定赚钱**（实验室），L1 用主业现金流养 AI，L2 靠融资/订单；
3. **商业化难度**：L0 > L1 > L2（但 L2 抗风险最弱）；
4. 不能拿 L0 的"理论"要求 L2，也不能拿 L2 的"合同"证明 L0。

## 六、结论

> **AI 商业化是三层池联动的结果：L0 有理论/能力，L1 有场景/资本，L2 有交付/订单；任何一层单独看都会失真。**

研究上：
- 看 L0：论文/模型/开源/人才；
- 看 L1：云/广告/capex/推理成本；
- 看 L2：算力收入/毛利率/OCF/应收；
- 不要把"大厂"当商业化保证，也不要把"小公司合同"当理论突破。
