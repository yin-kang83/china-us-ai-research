# 中美 AI 分层对照（L1–L5，2026-11-18）

> A 轨：按层比较，不打"中美总分"；每层标注数据来源与证据等级。
> 美国数据：SEC 10-K/20-F；中国数据：A/H 股公告/财报 + 公开信息。
> 仅研究，不构成投资建议。

## 一、L1 算力/芯片

| 项 | 美国 | 中国 |
|---|---|---|
| 代表公司 | NVIDIA、AMD、TSMC、AVGO | 华为昇腾、寒武纪、海光、中芯国际 |
| 财务规模（最近 FY） | NVDA 营收 2,159 亿美元、R&D 185 亿；AMD 346 亿、R&D 81 亿；TSM capex 304 亿美元 | 多数公司规模较小/未上市；华为未上市 |
| 关键指标 | GPU 供给、先进制程、CUDA 生态 | 昇腾生态、国产制程、算力自给 |
| 证据等级 | verified（SEC） | observed/inferred（公告/行业） |
| 判断 | **美国仍领先**：先进制程+GPU+生态 | 中国在国产替代/昇腾生态追赶，但制程受限 |

## 二、L2 云/数据中心

| 项 | 美国 | 中国 |
|---|---|---|
| 代表公司 | MSFT、GOOGL、AMZN、META | 阿里云、腾讯云、华为云、三大运营商 |
| 财务规模 | MSFT 营收 3,318 亿、capex 1,160 亿；AMZN 7,169 亿、capex 1,318 亿；GOOGL 4,028 亿、capex 915 亿；META 2,010 亿、capex 697 亿 | 阿里/腾讯/华为云收入未单独完整披露；A 股数据港/光环新网 IDC 可查 |
| 关键指标 | 云收入增速、AI capex、推理成本 | 云增速、智算中心上架率、电价 |
| 证据等级 | verified（SEC） | observed（财报/公告） |
| 判断 | **美国 capex/云规模领先**；中国在智算中心建设速度上快，但利用率/回报待验证 |

## 三、L3 模型

| 项 | 美国 | 中国 |
|---|---|---|
| 代表 | OpenAI、Google/DeepMind、Anthropic、Meta | DeepSeek、智谱、月之暗面、阿里 Qwen、百度文心 |
| 数据 | 私有公司无财报；模型/论文/榜单公开 | 多为未上市/大厂内部；模型/论文公开 |
| 关键指标 | 前沿能力、开源、论文/引用、训练算力 | 模型能力、开源、成本、应用落地 |
| 证据等级 | observed（公开 benchmark/论文） | observed/inferred |
| 判断 | **美国前沿模型仍领先**；中国在开源/低成本/工程化上强，差距在缩小但无统一结论 |

## 四、L4 工具链/平台

| 项 | 美国 | 中国 |
|---|---|---|
| 代表 | Microsoft（Copilot）、Google（Vertex）、Databricks（私有） | 范式智能、百度、阿里、华为 |
| 数据 | MSFT/GOOGL R&D 356/611 亿美元 | 范式 H1 收入 37.65 亿元、API +860.8%；其他未单列 |
| 关键指标 | 平台收入、开发者、API/Token | MaaS/Token、企业渗透 |
| 证据等级 | verified（美国大厂财务）；observed（范式） | observed/inferred |
| 判断 | **美国平台生态更成熟**；中国在 API/Token 变现上开始起量，但规模小 |

## 五、L5 应用

| 项 | 美国 | 中国 |
|---|---|---|
| 代表 | 软件/广告/云（MSFT/GOOGL/META） | 制造/政务/互联网 + 23 家 A/H 公司 |
| 数据 | 广告/云收入可查；AI 增量难拆分 | 23 家算力/应用公司合同/收入可查；应用收入多未单列 |
| 关键指标 | AI 渗透率、付费/复购 | 算力收入/毛利率/OCF、行业落地 |
| 证据等级 | verified/inferred（大厂） | observed（A 股公告/财报） |
| 判断 | **美国 AI 嵌入现有业务（广告/软件/云）变现更成熟**；中国多在算力/项目层，应用层变现仍早期 |

## 六、总体判断（分层）

| 层 | 美国 | 中国 | 差距/特点 |
|---|---|---|---|
| L1 算力/芯片 | 强 | 追赶 | 先进制程/GPU 生态差距 |
| L2 云/DC | 强（capex 巨大） | 快（建设快） | 规模/回报待验证 |
| L3 模型 | 领先 | 追赶（开源/低成本） | 前沿能力差距缩小 |
| L4 工具链 | 成熟 | 起步 | 平台/API 变现 |
| L5 应用 | 成熟（嵌入主业） | 早期（算力/项目） | 应用变现差距 |

## 七、证据缺口

1. 美国 AI 收入不单独披露，只能用 capex/R&D/云收入代理；
2. 中国云/模型公司多未上市或未单列 AI 收入；
3. 私有实验室（OpenAI/Anthropic/DeepSeek/智谱）无完整财报；
4. 算力利用率、推理成本、客户复购等关键数据缺失；
5. 需要补充：IDC/Gartner/Canalys（付费）、企业调研、招投标数据。

## 八、结论

> **美国强在"前沿模型+算力+云 capex+应用变现"；中国强在"工程化+建设速度+应用场景+成本"。**
> **没有"总分"，只有分层差距；中国公司当前多在 L1/L2，向 L3/L4 升级是关键。**
