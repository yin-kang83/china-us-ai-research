## 三、对照结论

| 维度 | 美国 | 中国 |
|---|---|---|
| 云规模 | AWS ~$148B、Azure >$100B、Google Cloud run-rate >$70B | 阿里云 ~1,581 亿元、天翼云 1,207 亿元 |
| 增速 | Azure +43%、Google Cloud +48%、AWS AI 相关高增 | 阿里云 +34%、联通云 +5.2% |
| AI 含量 | Azure/Google Cloud 明确 AI 驱动 | 阿里云 AI 相关占 30% |
| Capex | MSFT/GOOGL/AMZN 千亿美元级 | 运营商/阿里千亿人民币级 |
| 判断 | **规模+增速仍领先** | **增速追赶，AI 占比提升** |

## 四、注意

1. **财年/汇率不同**：MSFT FY2026、GOOGL FY2025、阿里 FY2026（截至 3/31）；
2. **云口径不同**：AWS/Azure/Google Cloud 含 IaaS/PaaS/AI；阿里云含公有云/混合云；运营商云含 IDC/云/算力；
3. **不能直接加总**得出"中美云差距"；
4. 数据来源为公开财报/媒体，引用以原文为准。

## 五、结论

> **美国云在"规模 + AI 增速 + capex"上仍领先；中国云在"增速/AI 占比"上追赶，但绝对规模与资本开支仍有差距。**
> L2 的差距不是"有没有云"，而是"AI 云的收入质量、毛利、capex 回报"。
