# 风险四象限分析（2026-11-18）

> 两轴：横轴=执行/收入证据（0–5）；纵轴=风险/信息不对称（0–10，分值越高越危险）。
> 气泡大小≈合同/需求规模。
> 评分只用于排序，不是造假结论；不构成投资建议。

## 一、象限定义

| 象限 | 含义 | 策略 |
|---|---|---|
| **高执行 + 低风险（理想）** | 已形成收入/现金流，风险低 | 重点跟踪、可给溢价 |
| **高执行 + 高风险（带病奔跑）** | 业务已兑现，但现金流/治理/负债有硬伤 | 盯现金流/治理，风险折价 |
| **低执行 + 高风险（纯风险）** | 合同/投入大，收入未验证，风险高 | 先验证执行，不参与 |
| **低执行 + 低风险（稳健待放量）** | 业务稳，但算力增量未放量 | 等放量催化 |

## 三、结论

1. **没有"高执行+低风险"的理想标的**：算力合同已兑现的公司，普遍伴随现金流/治理/负债风险；
2. **"带病奔跑"是主象限**：赛意、弘信、行云、康惠、东阳光都已出现收入/交付证据，但风险分 8–9；
3. **"纯风险"象限**：亿田、东方新能——合同/投入大，但算力收入未验证，且风险高（亏损/诉讼/预付）；
4. **数据港**是唯一"低风险"（4 分），但算力收入仅 0.02 亿（H1），属于"稳健待放量"；
5. **行云是"执行+现金流"最好的，但治理/内控风险最高**——典型"高执行+高风险"。

## 四、操作含义（研究层面）

- 高执行+高风险：重点验证**回款/OCF/内控整改**，不因收入增长给高估值；
- 低执行+高风险：先看**验收/收入/回款**是否出现，再谈其他；
- 低执行+低风险：等**算力收入放量**；
- 理想象限暂无：说明当前算力合同主题整体处于"高增长+高风险"阶段。

## 五、下一步

- 用 2026 年报/2027Q1 更新执行分与风险分；
- 若某公司进入"高执行+低风险"，才是真正值得重仓研究的对象；
- 若"低执行+高风险"持续，考虑剔除。
