# AI 纯度 × 风险矩阵（2026-11-18）

> 横轴：AI/算力收入纯度；纵轴：风险分（越高越危险）。
> 纯度为研究评分（0–10），风险分为既有评分；不是投资建议。

## 一、矩阵定位

| 象限 | 公司 | 含义 |
|---|---|---|
| **高纯度 + 高风险** | 平治信息（7,7）、弘信电子（6,8）、行云科技（5,8）、协创数据（4,7）、杰创智能（8,6）、中贝通信（6,6）、云从科技（4,6） | 真算力，但现金流/杠杆/治理有硬伤 |
| **高纯度 + 低风险** | 东华软件（4,4） | 相对平衡：业务相邻、OCF 正、风险中低；**AI收入未单列，纯度证据弱** |
| **低纯度 + 高风险** | 赛意信息（2,9）、东阳光（2,9）、康惠股份（2,9）、亿田智能（2,8）、东方新能（1,9）、科翔股份（1,8）、安博通（1,8） | 投入/故事大，纯度低或收入质量待核 |
| **低纯度 + 低风险** | 数据港（3,4）、光环新网（3,5）、宝信软件（2,3）、特锐德（1,3）、广电运通（2,4）、云赛智联（2,4）、华孚时尚（1,5）、安诺其（2,6） | 稳健/配套，但 AI 含量低 |

> 括号为（AI 纯度，风险分）。

## 二、关键结论

1. **没有"高纯度 + 低风险"的完美标的**；最接近的是**东华软件**（纯度 4、风险 4），但它的 AI 收入未单列；
2. **高纯度公司普遍带风险**：杰创、平治、弘信、行云、协创、中贝——真算力，但杠杆/现金流/客户集中；
3. **低纯度 + 高风险是最危险组合**：赛意、东阳光、康惠、亿田、东方新能、科翔、安博通；
4. **低纯度 + 低风险是"稳健但 AI 弹性小"**：数据港、光环、宝信、特锐德、广电、云赛；
5. **AI 纯度不是越高越好**：高纯度需要现金流/治理匹配；低纯度但真赚钱的配套公司也有价值。

## 三、对研究的含义

- **高纯度 + 高风险**：重点验证 OCF/回款/客户集中，不给"纯度溢价"；
- **高纯度 + 低风险**：东华是唯一接近的样本，需看 AI 收入能否单列；
- **低纯度 + 高风险**：先看收入质量/监管/现金流，不参与故事；
- **低纯度 + 低风险**：等 AI 放量，或按配套/IDC 逻辑看。
