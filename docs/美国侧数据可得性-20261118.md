# 美国侧数据可得性与采集方案（2026-11-18）

> 研究问题：美国侧数据的可得性与采集。
> 结论：**能取得，但要换数据源/口径**；SEC 免费 XBRL 是主力，AI 收入只能靠代理指标。

## 一、数据源（免费/可用）

| 来源 | 内容 | 可用性 |
|---|---|---|
| **SEC EDGAR companyfacts** | 10-K/10-Q/20-F 财务科目（营收、capex、R&D） | 免费 API，已验证可用 |
| **SEC submissions** | 公司文件列表、10-K/20-F 原文 | 免费 |
| **公司 IR/财报** | 云/AI 分部、指引、电话会 | 免费网页/PDF |
| **FRED/BEA** | 宏观、投资、GDP | 免费 |
| **UN Comtrade** | 芯片/服务器贸易 | 免费（有限额） |
| **NSF/NIST/白宫** | R&D、政策、标准 | 免费 |
| **Stanford AI Index/Epoch AI** | 模型/算力/论文 | 免费报告 |
| **媒体/智库** | 行业报道 | 免费但需交叉验证 |

## 二、主要限制

1. **AI 收入不单独披露**：MSFT/GOOGL/AMZN/META 只披露云/广告/分部，AI 是嵌入的；
2. **口径不一致**：Revenues vs RevenueFromContractWithCustomer；capex 科目不同；
3. **外国发行人用 IFRS**：TSM 20-F 不用 us-gaap，XBRL 标签不同；
4. **私有实验室无财报**：OpenAI/Anthropic/xAI 无 SEC 文件，只能靠公开报道/融资；
5. **付费数据缺**：IDC/Gartner/Canalys/Bloomberg/Wind 无预算。

## 四、建议的美国侧样本

| 层 | 公司 | 看什么 |

| L1 算力/芯片 | NVIDIA、AMD、TSMC、AVGO | 数据中心收入、capex、产能 |
