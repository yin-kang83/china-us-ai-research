## 二、四象限

| 象限 | 公司 | 含义 |
|---|---|---|
| **高纯度 + 高风险** | 杰创、平治、弘信、中贝、行云、协创、云从 | 真算力，但 OCF/杠杆/治理有硬伤 |
| **高纯度 + 低风险（相对）** | 东华（AI 收入未单列，证据弱） | 业务相邻、OCF 正、风险中低 |
| **低纯度 + 高风险** | 赛意、康惠、亿田、东阳光、东方新能、科翔、安博通 | 故事大/纯度低/收入质量待核 |
| **低纯度 + 低风险** | 宝信、数据港、光环、特锐德、广电、云赛、华孚、安诺其 | 稳健/配套，AI 弹性小 |

## 三、分组结论

| 组 | 公司 | 特征 |
|---|---|---|
| **真算力收入 + 高风险** | 杰创、平治、弘信、中贝、行云、协创、云从 | 收入出现，但 OCF/杠杆/治理 |
| **业务相邻 + 相对稳健** | 东华 | 软件底盘、腾讯云、OCF 正；AI 收入未单列 |
| **重资产/建设期** | 科翔、亿田、华孚、东方新能、康惠、赛意 | 投入大、收入未验证 |
| **稳健/低风险** | 宝信、数据港、光环、特锐德、广电、云赛 | 财务稳，AI 弹性小 |
| **监管/收入质量待核** | 安博通 | 贸易占 59%、供应商集中且新进 |
