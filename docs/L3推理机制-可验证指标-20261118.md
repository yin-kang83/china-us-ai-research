# L3 推理机制 → 可验证指标（2026-11-18）

> 原则：只写公开可说的机制；不猜内部架构；用"机制 → 指标"替代"独门理论"叙事。
> 适用：中美 AI 分层对照的 L3 模型层。

## 一、共性推理链路

```
预训练（next-token / 多模态）
  → 后训练（SFT、RLHF/RLAIF、RLVR/可验证奖励、拒绝采样）
  → 推理时（CoT/延长思考、自一致性、搜索、工具调用）
  → Agent（规划、记忆、函数调用、执行）
```

> 头部模型的差异主要在**数据、算力、工程、成本**，不是"每家一套基础理论"。

1. **机制趋同**：预训练+RL+CoT+工具是共同路径；
2. **差异在工程/成本/数据**，不在"独门理论"；
3. **对外报告**：用"机制→指标"，不写内部架构猜测；
