# L4 工具链 / L5 应用：中美对照（2026-11-18）

> 目标：补齐 A 轨的"平台/工具链"和"应用/变现"两层。
> 原则：有公开数据的量化；没有的标 observed/unknown；不做中美总分。

## 一、L4 工具链/平台

| 层 | 美国 | 中国 |
|---|---|---|
| **云 AI 平台** | Azure AI Foundry、AWS Bedrock、Google Vertex AI | 阿里百炼、百度千帆、华为 ModelArts、腾讯云 TI |
| **办公/代码助手** | Microsoft 365 Copilot、GitHub Copilot | 钉钉 AI、飞书智能伙伴、通义灵码、文心快码 |
| **数据/模型平台** | Databricks、Snowflake Cortex | 星环、达梦、范式先知 |
| **开发者生态** | 成熟（API/SDK/市场） | 成长中（开源/私有化强） |

| 指标 | 数值 | 来源/口径 |
|---|---:|---|
| Azure 年度收入 | **>1,000 亿美元** | Microsoft FY2026（媒体） |
| Microsoft 365 Copilot 付费席位 | **3,000 万** | Microsoft FY2026 Q4（媒体） |
| Google Cloud 2025Q4 收入 | **177 亿美元（+48%）** | Alphabet FY2025 |
| Gemini App MAU | **7.5 亿** | Alphabet FY2025 |

| 范式 API 收入增速 | +860.8% | 范式 2026 中报 |

> 缺口：AWS Bedrock/Vertex/百炼/千帆的平台收入、开发者数、API 调用量多数未单列；上表只能做"有/无、快/慢"的判断。

### L4 判断

1. **美国平台生态更成熟**：Azure/AWS/Google Cloud 把模型、工具、计费、企业合同打通；
2. **中国平台更偏"垂直+私有化"**：百炼/千帆/ModelArts 在政企、制造、国产化场景强；
3. **办公/代码助手是变现前沿**：Copilot 3,000 万席位是"AI 订阅制"最硬的证据之一；
4. **中国平台收入不透明**：除阿里云 AI 占比、范式 API 增速外，缺少可比的平台收入。

## 二、L5 应用/变现

| 场景 | 美国 | 中国 |
|---|---|---|
| **广告** | AI 提升推荐/创意，广告收入可查 | 字节/腾讯/阿里广告 AI 化，增量难拆分 |
| **软件/办公** | Copilot 订阅、按席位收费 | 钉钉/飞书 AI 功能，付费转化早期 |
| **云** | AI 云收入高增（Azure/Google Cloud） | 阿里云 AI 占比 30%，运营商云增长 |
| **消费应用** | Gemini App 7.5 亿 MAU | 豆包/Kimi/元宝等，MAU 数据待补 |
| **制造/政务** | 工业 AI 渗透，项目制 | 23 家算力/行业公司，场景多、变现早期 |

### 可量化证据

| 指标 | 数值 | 来源 |
|---|---:|---|
| Gemini App MAU | 7.5 亿 | Alphabet FY2025 |
| Microsoft 365 Copilot 付费席位 | 3,000 万 | Microsoft FY2026 Q4 |
| 阿里云 AI 相关占云收入 | 30% | 阿里 20-F FY2026 |
| 中国 23 家算力公司 | 多数 AI/算力收入未单列或占比低 | 本项目 23 家评分 |

### L5 判断

1. **美国变现更成熟**：广告/软件/云三条线都有可查的 AI 收入或付费席位；
2. **中国场景更分散**：制造/政务/消费都有，但"AI 收入单列"少、付费率低；
3. **消费应用是中国的亮点**：豆包/Kimi/元宝等 MAU 高，但商业化（订阅/广告）仍在早期；
4. **制造 AI 是长期变量**：项目制、ROI 慢，但一旦跑通常态化付费。

## 三、综合结论

| 层 | 美国 | 中国 | 差距性质 |
|---|---|---|---|
| **L4 工具链** | 平台生态成熟、订阅变现 | 垂直/私有化、开源/成本 | **生态差距** |
| **L5 应用** | 广告/软件/云变现成熟 | 场景多、付费早期 | **变现差距** |

> **美国强在"平台+订阅+广告"的变现闭环；中国强在"场景密度+工程成本"，但平台收入/付费数据不透明。**
> 下一步要补：平台收入、开发者数、API 调用、AI 应用 MAU/付费率。
