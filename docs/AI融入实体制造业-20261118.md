# AI 融入实体制造业：路径与指标（2026-11-18）

> 研究问题：AI 如何融入实体制造业并产生价值。
> 研究含义：制造业 AI 的价值不在"卖算力"，在"降本、提效、提质、创新"。

## 一、制造业 AI 的四层

| 层 | 场景 | 价值 | 难度 |
|---|---|---|---|
| **L1 设备/产线** | 机器视觉质检、预测性维护、参数优化 | 降本、减少停机 | 中（数据/OT） |
| **L2 生产运营** | 排产、供应链、库存、能耗 | 提效、降库存 | 中高（系统集成） |
| **L3 研发设计** | 生成式设计、仿真、工艺优化 | 缩短研发周期 | 高（数据/人才） |
| **L4 商业模式** | C2M、服务化、AI 质检即服务 | 增收/新业务 | 高（组织） |

## 二、价值杠杆（可量化）

| 杠杆 | 指标 |
|---|---|
| 降本 | 单位成本、能耗、废品率 |
| 提效 | OEE、人均产值、交付周期 |
| 提质 | 良率、漏检率、客诉率 |
| 降库存 | 库存周转、在制品 |
| 创新 | 新品开发周期、设计迭代次数 |

## 三、23 家公司里谁最该"用 AI 改造自己"

| 类型 | 公司 | 可用场景 |
|---|---|---|
| **制造型（最适合）** | 华孚时尚（纺织，13,140 人）、科翔（PCB，5,306 人）、亿田（厨电，490 人）、康惠（医药）、安诺其（染料）、东阳光（电子材料/化工）、弘信/协创（电子） | 质检、排产、工艺、能耗、供应链 |
| **装备/电力** | 特锐德（电力设备，9,030 人） | 质检、预测维护、排产 |
| **工业软件赋能者** | 赛意（工业软件+AI）、东华（行业模型）、宝信（工业软件+IDC） | 帮别人落地 |
| **基础设施** | 数据港/光环/中贝 | 为制造 AI 提供算力，不是自己用 |

## 四、现实障碍

1. **数据孤岛/质量差**：设备数据、MES/ERP 不打通；
2. **OT/IT 融合难**：工业协议、老设备；
3. **ROI 不确定**：试点有效、规模化难；
4. **人才缺**：既懂工艺又懂 AI；
5. **安全/合规**：数据、模型可靠性；
6. **中小企业买不起**：需要 SaaS/按效果付费。

## 五、正确路径

1. **先场景后平台**：选 1–2 个高 ROI 场景（质检/排产/能耗）试点；
2. **算清 ROI**：用良率/能耗/停机时间说话，不用"AI 合同金额"；
3. **数据先行**：设备联网、数据治理；
4. **轻量化**：SaaS/边缘 AI，别一上来建大平台；
5. **按效果付费**：AI 质检按件、节能按分成；
6. **复制推广**：从一个车间到全厂、从一家到产业链。

## 六、跟踪指标（B 轨新增）

| 指标 | 含义 |
|---|---|
| AI 场景渗透率 | 多少产线/工序用上 |
| 良率/漏检率变化 | 质量 |
| 单位能耗/成本 | 降本 |
| OEE/交付周期 | 提效 |
| 库存周转 | 运营 |
| AI 相关收入/节省 | 价值量化 |

## 七、结论

> **AI 的威力不在"建多少智算中心"，在"多少工厂真正用起来、良率/能耗/交付有没有改善"。**
> 对制造型公司，最现实的路是"用 AI 改造自己"，而不是都去当算力运营商；
> 对赛意/东华/宝信，机会是"帮制造业落地"；
> 对数据港/光环/中贝，是"卖铲子"，但要看到制造客户的上架率/复购。
