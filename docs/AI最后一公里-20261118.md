# 打通 AI 的"最后一公里"（2026-11-18）

> 最后一公里 = 从"算力建成/合同签订"到"客户真正用起来、付钱、复购、回款"。
> 不是再建多少算力，而是**需求侧/应用侧**能不能接住。

## 一、最后一公里的五个环节

| 环节 | 关键动作 | 失败表现 |
|---|---|---|
| 1. 算力建成 | 服务器到货、机房通电、集群调试 | 设备闲置、延期 |
| 2. 客户接入 | 客户迁移/适配/压测 | 客户观望、订单取消 |
| 3. 应用上线 | 模型/Agent/行业应用部署 | 只有算力没有应用 |
| 4. 生产嵌入 | 进入客户生产/业务流程 | 试点无法规模化 |
| 5. 付费复购 | 按 token/订阅/服务收费、回款 | 应收高、OCF 负 |

## 二、19 家公司的"最后一公里"位置

| 阶段 | 公司 | 判断 |
|---|---|---|
| **只有设备/材料，没到算力** | 科翔（AI PCB 建设期）、特锐德（电力配套） | 卖铲子，最后一公里不在自己手里 |
| **有算力/合同，客户未验证** | 赛意（83 亿合同/OCF-15.95 亿）、杰创（49 亿匿名合同）、中贝（7.4 亿中标未签合同） | 合同≠收入，验收/回款是关键 |
| **有算力收入，但偏租赁/贸易** | 行云、平治、安诺其、康惠、亿田、东阳光 | 收入真，但毛利率/粘性待验证 |
| **有平台/MaaS，规模小** | 中贝（MaaS/Token）、东华（腾讯云/行业模型）、云从（AI 平台） | 方向对，收入占比小 |
| **最接近生产融入** | 赛意（工业软件+AI）、东华（行业大模型/WorkBuddy） | 有场景，但需财报验证 |
| **IDC 为主** | 数据港 | 稳健，但 AI 应用层弱 |

## 四、最后一公里的核心指标

| 指标 | 为什么重要 |
|---|---|
| 算力利用率/上架率 | 建了有没有人用 |
| 算力业务毛利率 | 卖算力 vs 卖服务 |
| Token/Agent/订阅收入 | 是否升级到应用层 |
| 合同负债/预收 | 客户是否先付钱 |
| 应收/营收、账龄 | 回款质量 |
| OCF/净利 | 利润是否变现金 |
| 客户集中度/复购 | 生产嵌入深度 |

## 五、结论

1. **最后一公里不是"再建算力"，是"找到用算力的人"**；
2. 目前多数公司停在"有算力/有合同"，没到"客户生产嵌入/复购"；
3. **最可能打通的是有场景的公司**：赛意（工业软件）、东华（行业模型/腾讯云）；
4. **纯算力租赁/贸易公司**会被商品化，毛利率/现金流是硬约束；
5. 2026 年报/2027Q1 重点看：**毛利率、预收、应收、OCF**，而不是合同金额。
