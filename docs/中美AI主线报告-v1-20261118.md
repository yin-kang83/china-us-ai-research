# 中美 AI 主线报告 v1（2026-11-18）

> 研究问题：中美 AI 竞争，到底差在哪一层？
> 方法：L1–L5 分层对照；每层用可核查数据/证据等级；不做"中美总分"；不构成投资建议。
> 数据截至：2026-11-18；美国公司财年不同（MSFT 6 月、GOOGL/AMZN 12 月），中国公司为 2025 年报/2026H1。

## 一、执行摘要（五句话）

1. **美国仍领先"能力+资本+生态"**：前沿模型、先进算力、云 capex、应用变现；
2. **中国强在"工程+成本+场景+速度"**：开源模型、智算建设、制造/政务场景；
3. **差距是分层的，不是总分**：L1 硬差距、L2 规模差距、L3 能力差距缩小、L4 生态差距、L5 变现差距；
4. **模型正在商品化**：开源权重模型占 OpenRouter token 约 72%，价值向工作流/数据/场景转移；
5. **最大不确定性**：AI 需求能否消化巨额 capex，以及先进算力/出口管制。

## 二、分层对照

| 层 | 美国 | 中国 | 差距性质 | 关键证据 |
|---|---|---|---|---|
| **L1 算力/芯片** | NVIDIA/AMD/TSMC/AVGO 领先 | 华为昇腾/寒武纪/海光/中芯/北方华创/中微 | **硬差距**：先进制程/GPU 生态 | NVIDIA 营收 2,159 亿美元、R&D 185 亿；中芯营收 673 亿元、capex 600 亿元 |
| **L2 云/DC** | AWS ~$148B、Azure >$100B、Google Cloud >$70B run-rate | 阿里云 1,581 亿元、天翼云 1,207 亿元 | **规模差距** | MSFT/AMZN/GOOGL/META capex 千亿美元级 |
| **L3 模型** | Claude/GPT/Grok 领先 | Kimi/Qwen/DeepSeek 第一梯队 | **能力差距缩小** | AAII：Claude Opus 5 63、Kimi K3 60、Qwen 56、DeepSeek 53；开源 token 份额 72% |
| **L4 工具链** | Microsoft/Google/Databricks 生态成熟 | 范式/百度/阿里/华为（垂直/私有化） | **生态差距** | 美国平台收入未单列；中国范式 API +860.8% |
| **L5 应用** | AI 嵌入广告/软件/云，变现成熟 | 制造/政务/互联网场景多，变现早期 | **变现差距** | 美国广告/云收入可查；中国 23 家公司算力收入多未单列 |

## 三、三条主线判断

### 1. 美国：强在"从模型到现金流"的闭环

- 前沿模型（Claude/GPT/Grok/Gemini）+ 云（AWS/Azure/Google Cloud）+ 应用（广告/软件/Copilot）；
- 用主业现金流养 AI：MSFT OCF 1,829 亿美元、GOOGL 1,647 亿、AMZN 1,395 亿；
- 风险：capex 过高（AMZN capex/OCF 约 94%）、ROI 待验证、电力/土地约束。

### 2. 中国：强在"从场景到规模"的工程能力

- 开源模型（Kimi/Qwen/DeepSeek）在能力上接近第一梯队、成本低；
- 智算中心/IDC 建设快，阿里云/运营商云增速追赶；
- 制造/政务/消费场景多，但企业付费/软件生态弱；
- 风险：先进算力受限、企业软件付费意愿低、部分公司"AI 名义+贸易实质"。

### 3. 竞争是"错位"而非"单点胜负"

- 美国赢在 L1/L3/L4/L5 的"能力+生态+变现"；
- 中国赢在 L2 的"建设速度"、L3 的"开源/成本"、L5 的"场景密度"；
- 双方都在补短板：美国补电力/制造，中国补算力/软件生态。

## 四、关键不确定性

| 不确定性 | 影响 |
|---|---|
| AI 需求能否消化 capex | 若不及预期，云/芯片/供应链先受伤 |
| 先进算力/出口管制 | 中国 L1 追赶速度 |
| 模型商品化/价格战 | 平台/应用价值向工作流转移 |
| 企业付费/ROI | 中国 L5 变现速度 |
| 政策/监管 | 数据、标准、合规成本 |

## 五、证据缺口

1. **L1**：中国算力进口/国产替代/实际算力规模；华为未上市；
2. **L2**：中国云利润率/利用率；美国云 AI 收入拆分；
3. **L3**：LMArena/Elo、真实企业任务评测、开源下载/部署量；
4. **L4**：平台收入/开发者/API 调用；
5. **L5**：AI 应用收入/企业渗透/付费复购；
6. **政策/标准**：采用率/合规成本/落地效果。

## 六、结论

> **美国强在"能力+资本+生态+变现"，中国强在"工程+成本+场景+速度"；没有"中美总分"，只有分层差距。**
> 下一阶段的关键不是"谁喊得响"，而是：**谁能把 AI 变成可复用的生产力，并且收得回现金。**
