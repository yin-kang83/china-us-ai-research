## 三、怎么解读

| 维度 | 美国 | 中国 |
|---|---|---|
| 前沿闭源模型 | Claude/GPT/Grok 仍居前列 | Kimi/Qwen/DeepSeek 紧随 |
| 开源权重 | Llama/Nemotron 等 | Kimi/Qwen/DeepSeek 主导开源生态 |
| Token 份额 | 闭源 API 份额被开源侵蚀 | 开源模型吃下大部分常规流量 |
| 成本 | 高 | 低（开源/自托管） |
| 结论 | **前沿能力仍领先** | **能力差距缩小、成本优势明显** |

## 四、关键判断

1. **能力**：美国前沿闭源模型仍领先，但中国头部模型已进入第一梯队（Kimi K3 第 4、Qwen 第 5、DeepSeek 第 6）；
2. **成本/份额**：开源权重模型占 OpenRouter token 约 72%，中国开源模型是主要受益者；
3. **商业化**：模型能力商品化 → 价值向"工作流/数据/场景"转移（与 Morgan Stanley 判断一致）；
4. **风险**：单一榜单可能被优化/污染；模型版本更新快；需结合 LMArena/真实任务评测。
