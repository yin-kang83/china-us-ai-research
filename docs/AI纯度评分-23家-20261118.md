# 23 家公司 AI 纯度评分（2026-11-18）

> 研究性评分，不是投资建议。AI 纯度 = 收入中"AI/算力服务"的实质含量，≠ 公司价值。
> 依据：2025 年报/2026H1 分部、合同、现金流、客户/供应商、可持续性。

## 一、评分口径（0–10）

| 维度 | 分值 | 说明 |
|---|---:|---|
| AI/算力收入占比 | 0–4 | ≥40%=4；20–40%=3；10–20%=2；<10%=1；无单列=0 |
| 收入质量/毛利 | 0–2 | 服务/平台高；硬件贸易/低毛利低 |
| 现金流 | 0–2 | OCF 正=2；负=0–1 |
| 可持续/客户分散 | 0–2 | 一次性/客户集中=0–1；持续/分散=2 |

> 评分是研究排序，不替代财务/法律尽调；数据以公告/财报为准。

## 三、分层

| 层 | 公司 |
|---|---|
| **高纯度（7–8）** | 杰创、平治 |
| **中纯度（4–6）** | 弘信、中贝、行云、协创、云从、东华 |
| **低纯度（2–3）** | 数据港、光环、赛意、宝信、云赛、广电、康惠、亿田、安诺其、东阳光 |
| **最低（0–1）** | 科翔、特锐德、华孚、东方新能、安博通 |

## 四、结论

1. **AI 纯度最高的是"真算力服务"**：杰创、平治；但两者都有杠杆/现金/研发问题；
2. **中纯度是算力制造/IDC/软件+算力**：弘信、中贝、行云、协创、云从、东华；
3. **低纯度多为跨界/配套/大集团小 AI**：赛意、数据港、光环、宝信等；
4. **最低纯度是"贸易/无收入/配套"**：安博通、科翔、东方新能等；
5. **AI 纯度高 ≠ 值得投**：还要看现金流、杠杆、治理；反之配套/硬件也能赚钱。

## 五、使用限制

- 收入占比来自公开分部数据，部分公司未单列 AI，评分为近似；
- 贸易/净额法收入按"实质"降权；
- 评分会随 2026 年报/2027Q1 更新。
